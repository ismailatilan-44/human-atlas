## Evidence vocabulary

- **Verified:** a specified record, source claim, or observation was checked; the object of verification must be named. A checked source page does not verify model anatomy or learning efficacy.
- **Proposed:** an author recommendation or design hypothesis, not a user-selected product requirement.
- **Untested:** a possible mechanism or claim lacks the relevant practical evaluation.
